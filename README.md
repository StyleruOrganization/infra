# Infra

Общая инфраструктура проектов: Docker, маршрутизация, мониторинг,
центральные GitHub Actions и зашифрованные SOPS-секреты.

- `hosts/` — настройки серверов.
- `projects/` — конфигурация каждого проекта.
- `modules/` — общие компоненты.
- `.github/workflows/` — ручные релизы инфраструктуры и приложений.
- `tools/manage_secrets.py` — создание и редактирование секретов.

Исходники приложений находятся в отдельных репозиториях.
Приватные ключи и расшифрованные `.env` в Git не хранятся.

## EventRadar

Проект `event-radar`, сервис `bot` получает исходники из
`StyleruOrganization/event-radar`. Используйте `Release infrastructure`
для подготовки окружения и `Release service` для обновления приложения.
Стратегия `recreate` предназначена для единственного polling-процесса с SQLite.
Она выполняет preflight в одноразовом контейнере, останавливает старую версию,
запускает резервное копирование и заменяет приложение после успешного бэкапа.
При сбое запуска сохраняется диагностика и повторно запускается старый контейнер.

Порядок переноса данных и авторизации находится в `infra/DEPLOY.md`
репозитория приложения. Перед первым релизом создайте SOPS-секреты проекта
через `tools/manage_secrets.py` и импортируйте ChatGPT-сессию.
Первый запуск создаёт пустую базу, каналы и промпты владелец задаёт заново.
