# Infra

Общая инфраструктура проектов: Docker, маршрутизация, мониторинг,
центральные GitHub Actions и зашифрованные SOPS-секреты.

- `hosts/` — настройки серверов.
- `projects/` — конфигурация каждого проекта.
- `modules/` — общие компоненты.
- `.github/workflows/` — ручные релизы инфраструктуры и приложений.
- `tools/manage_secrets.py` — создание и редактирование секретов.

Исходники приложений находятся в отдельных репозиториях.
Приватные ключи и расшифрованные `.env` в Git не хранятся.
